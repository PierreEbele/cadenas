# cadenas

> Chiffrez un fichier avec un mot de passe, simplement.

**cadenas** est un outil open source pour chiffrer et déchiffrer un fichier avec un
mot de passe, directement dans le navigateur (rien n'est envoyé à un serveur) ou en
ligne de commande.

🚧 Projet en cours de développement.
