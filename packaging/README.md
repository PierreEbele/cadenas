# Homebrew and winget packages

**English** · [Français](README.fr.md)

The manifests in this folder are generated by `scripts/packaging.js` for an
**already published** version: checksums are read from the `SHA256SUMS` of
the GitHub release and from the npm package.

```bash
node scripts/packaging.js 1.5.0
```

## Homebrew (macOS, Linux)

`homebrew/cadenas.rb` installs the npm package with Homebrew's Node.js, like
the Node.js formulas in homebrew-core.

**Once**: create the public repository `PierreEbele/homebrew-cadenas` (the
`homebrew-` prefix is mandatory) with a `Formula/` folder.

**For each version**: copy `homebrew/cadenas.rb` to `Formula/cadenas.rb` in
that repository, then check:

```bash
brew install --build-from-source ./Formula/cadenas.rb
brew test cadenas
brew audit --strict --online cadenas
```

Installation for users:

```bash
brew install pierreebele/cadenas/cadenas
```

## winget (Windows)

`winget/manifests/…` describes the standalone Windows executable of the
release, installed as a "portable" application (`cadenas` command).

**For each version**: submit the version folder to
[microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs), with a
pull request from a fork, or with
[wingetcreate](https://github.com/microsoft/winget-create):

```powershell
winget validate --manifest packaging\winget\manifests\p\PierreEbele\cadenas\1.5.0
winget install --manifest packaging\winget\manifests\p\PierreEbele\cadenas\1.5.0
wingetcreate submit packaging\winget\manifests\p\PierreEbele\cadenas\1.5.0
```

Installation for users, once the pull request is accepted:

```powershell
winget install PierreEbele.cadenas
```
