cadenas

Chiffrez un fichier avec un mot de passe. Rien ne quitte votre navigateur.

Mot de passe

Notez cette phrase de passe maintenant : elle ne pourra pas être retrouvée.

Format

Le nom d’origine est rangé à l’intérieur du fichier chiffré, qui reçoit un nom neutre.

Astuce : une phrase de 4 ou 5 mots est facile à retenir et très solide. Un mot de passe oublié ne peut pas être récupéré.

100 % local

Le chiffrement a lieu dans votre navigateur. Aucun fichier ni mot de passe n'est envoyé, et le site fonctionne même hors ligne.

Solide

Argon2id et XChaCha20-Poly1305 : toute modification du fichier chiffré est détectée.

Ouvert

Code source libre, format documenté, compatible avec l'outil age.
